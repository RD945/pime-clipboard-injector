# Security Policy

## Supported Versions

Security fixes are applied to the latest version of the project. Older copies
of the package are not maintained separately, so reproduce an issue with the
latest version before reporting it when possible.

## Reporting a Vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/RD945/pime-clipboard-injector/security/advisories/new).
Do not open a public issue for a vulnerability that has not been disclosed.

Include the following information where applicable:

- The affected files and project version or commit
- The Windows version and application architecture
- Reproduction steps or a minimal proof of concept
- The expected and observed behavior
- The security impact and any known mitigations

Do not include credentials, personal data, or other third-party secrets in a
report. Reports can be updated privately if additional evidence becomes
available.

This project is based on [EasyIME/PIME](https://github.com/EasyIME/PIME). If an
issue affects an unmodified upstream component rather than this project's
packaging or clipboard behavior, report it to the upstream maintainers using
their preferred security process.

The vulnerability can be discussed publicly after a fix or coordinated
disclosure is ready.
